// How Skills Work — Dock Magnification
01
Skills are instruction folders
A skill is a folder containing a SKILL.md file plus any supporting scripts, data, or references. Claude reads these at session start and uses them as specialised knowledge for specific tasks.
02
They activate automatically
You don't invoke most skills by name. Claude reads all installed SKILL.md files and activates the right one based on your request. Ask to build a landing page and the frontend skill fires.
03
They're lightweight
Skills load ~100 tokens at session start — far less than an equivalent MCP server. Multiple skills can be active simultaneously without significant performance impact.
04
Anyone can write one
A skill is just markdown. Encode your design system, component patterns, team conventions — available in every session without re-explaining yourself.
05
Skills vs prompts vs MCP
Prompts are one-shot. Skills persist across sessions and activate by context. MCP servers give live tool access but consume more tokens. Use skills for expertise; MCP for live data.
06
Claude Code only
Skills require the terminal-based agent, not claude.ai. Install via npm install -g @anthropic-ai/claude-code to get started.
