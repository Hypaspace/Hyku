Installation Guide
01
Install Claude Code
Requires Claude Code — Anthropic's terminal coding agent. Install globally via npm.
$ npm install -g @anthropic-ai/claude-code
02
Create your skills folder
Global skills are available across all projects. Project-scoped skills stay local.
$ mkdir -p ~/.claude/skills # global
$ mkdir -p .claude/skills # project
03
Install a skill
Pick your method. Plugin command is fastest.
$ /plugin marketplace add pbakaus/impeccable
$ git clone https://github.com/pbakaus/impeccable
$ cp -r impeccable/dist/claude/.claude/skills/impeccable ~/.claude/skills/
$ npm install -g uipro-cli && uipro init --ai claude
04
Verify & use
Open Claude Code and confirm skills are available.
$ claude
› /skills list
05
Skills activate automatically
◈ You don't need to invoke skills by command name. Claude reads your installed SKILL.md files and activates the right one based on context. You can also call them explicitly using the /command syntax shown in this guide.
◈ Start with Impeccable — the most complete design quality toolkit and the best single starting point. Grab Impeccable →
